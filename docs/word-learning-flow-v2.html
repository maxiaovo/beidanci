01 · 每日入口
VOCABULARY LEARNING LOOP

单词怎么学，为什么能记牢？

系统每天先安排到期复习，再按词书计划下发新词；复习没清完，新词默认不解锁。

📅 先过“到期复习”门禁

按到期时间从早到晚出题，最多取当天复习上限。普通检查用默认的拼写或选择；强检查则每词两种题都要过，并交错出题。

✍️ 两种主动回忆

拼写：看中文＋词性，写英文。
选择：看英文＋音标/发音，四选一中文释义。

答错或“想不起来” → 先显示答案，再把该题型随机插到后面（至少隔一题），连续答对 3 次才修复；中途再错，连对数清零。强检查中，另一题型若已过，也要再过 1 次。

管理员允许时可跳过门禁，但会留下家长可见记录，未复习的词不会消失，而会继续累积。

02 · 新词五步

每个新词都必须走完 5 步，最后自测通过才算学会

学习队列来自所选词书：可按“每天固定词数”或“当前单元的几分之一”设置；未单独设计划时使用每日新词目标。

1 认识

看英文与音标
点击听单词发音

2 拆解

词根/前后缀
中文释义＋记忆法

3 语境

听 2 条例句
中英对照，高亮目标词

4 拼写

跟浅色字形输入
扩展模式再抄 2 例句

5 自测

只看中文＋词性
默写完整英文

自测正确 → 记录“已学”并进入下一词。答错或放弃 → 显示正确拼写和音标，排到本次队尾，从“认识”重新完整学一遍再测，直到通过。
03 · 记忆阶梯

不是学一遍就结束，而是在越来越长的间隔里反复提取

新词自测通过后，进入第 1 阶段；以后每次到期检查“一遍通过”，就向上晋一级。

↺ 答错/放弃：重置

先回到阶段 0（10 分钟起点）；本轮连对 3 次修复后回到阶段 1，1 天后再查。

想额外加练可进入“自由练习”，自行选拼写或选择；它不会改变首页推荐的今日主任务顺序，但作答仍会留下学习记录。

04 · 家长陪伴

家长不替孩子答题，但能看见过程、调节节奏、及时鼓励

📊 看进度

今日/累计练习、正确率、待复习数、已学词数、连续学习天数，以及每个词的正确/错误/放弃记录。

🎚️ 调任务

为孩子设置每日新词目标（1–200）和每日复习上限（1–500）；跳过复习也会显示未完成数量。

💬 给鼓励

留言可设为开始学习时、学习 N 分钟后或学到第 N 个词时弹出，并设置有效期。

家长账号没有学习权限，学习操作始终由孩子完成。核心闭环：计划 → 复习 → 新学 → 自测 → 间隔复习 → 掌握
